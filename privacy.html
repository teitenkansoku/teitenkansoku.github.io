プライバシーポリシー

制定日: 2026年10月28日

1. このポリシーの対象

YouTube チャンネル「マーケット定点観測」（以下「本チャンネル」）と、本チャンネルの運営者が動画の投稿に使うアプリケーション（Google Cloud プロジェクト「market-news」、以下「本アプリ」）に適用します。

2. 本アプリが使う情報

本アプリは YouTube API Services を使用し、運営者本人の Google アカウントで認証して、運営者の YouTube チャンネルに動画・サムネイル・字幕をアップロードします。

  • 使う権限: 動画のアップロード（youtube.upload）、字幕の登録（youtube.force-ssl）
  • 認証の情報（アクセストークン）は運営者のパソコンにだけ保存し、第三者に提供しません。
  • 本アプリは、運営者以外のユーザーの Google アカウントやYouTube のデータにアクセスしません。視聴者の個人情報を集めることもありません。

3. YouTube と Google のポリシー

本アプリは YouTube API Services を使用しています。YouTube の利用には YouTube 利用規約 が適用され、データの扱いには Google プライバシーポリシー が適用されます。

本アプリに与えた許可は、Google アカウントのセキュリティ設定 からいつでも取り消せます。

4. データの保存期間と削除

  • 本アプリは YouTube API Services から取得したデータ（動画のID、字幕の一覧など）を、アップロードが成功したかの確認にだけ使い、統計情報などを保存・蓄積しません。
  • 認証の情報（アクセストークン・更新トークン）は、運営者のパソコンの1つのファイルにだけ保存します。許可を取り消すか、本アプリの利用をやめたときは、このファイルを7日以内に削除します。
  • YouTube API Services から取得したデータを保存した場合も、30日を超えて保存せず、それより前に削除または更新します。
  • Google アカウントのセキュリティ設定で本アプリへの許可を取り消すと、本アプリは YouTube のデータにアクセスできなくなります。

5. 視聴者の情報

本チャンネルのコメントや再生数などは YouTube が管理しており、運営者は YouTube の画面で見られる範囲のみを閲覧します。運営者が視聴者の個人情報を独自に収集・保存することはありません。

6. 変更

このポリシーを変更するときは、このページを更新します。

7. お問い合わせ

本ポリシーや本チャンネルについてのお問い合わせ: ainyuse（アット）gmail.com

Privacy Policy (English summary)

This application ("market-news", used by the operator of the YouTube channel "Market Teiten Kansoku") uses YouTube API Services only to upload videos, thumbnails and captions to the operator's own YouTube channel.

  • Scopes: youtube.upload and youtube.force-ssl (captions). The app does not access any other user's account or data, and does not collect viewers' personal information.
  • OAuth tokens are stored only in one file on the operator's computer and are never shared. They are deleted within 7 days after access is revoked or the app is no longer used.
  • API data is used only to confirm uploads; it is not stored for more than 30 days.
  • By using YouTube through this app, you are agreeing to be bound by the YouTube Terms of Service. See also the Google Privacy Policy. Access can be revoked at any time via the Google security settings page.
