マーケット定点観測

日本株・米国株・為替・暗号資産・人気の投資信託の動きを、毎日決まった時間に、決まった形でお届けする YouTube チャンネルです。

YouTube チャンネル

番組

  • 朝の定点観測（火〜土の朝）: 前日の米国市場、シカゴ日経先物とADRで見る寄り付きの目安、業種別の騰落、為替、暗号資産、きょうの予定
  • 夜の定点観測（月〜金の夜）: その日の東京市場、欧州株と米国株先物、為替、暗号資産、今夜とあすの予定
  • 投信の定点観測（月〜金の夜）: 人気の投資信託の基準価額と、値動きの理由（株価の分と為替の分）

作り方

動画は、公開されている市場データをもとに、プログラムでチャートと画面を作り、AI で原稿と読み上げ音声を作成しています。 出典は各動画の概要欄に記載しています。内容に誤りがある場合があります。

このサイトのアプリケーション（Google Cloud プロジェクト）は、運営者が自分の YouTube チャンネルに動画・サムネイル・字幕をアップロードするためだけに、YouTube Data API を使用します。
